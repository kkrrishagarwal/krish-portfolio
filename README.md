# Krish Agarwal - Developer Portfolio 🚀

A modern, interactive developer portfolio showcasing full-stack projects, cybersecurity tooling, and software engineering experience. Built with a sleek cyber-terminal aesthetic, smooth animations, and interactive components.

🌐 **Live Demo:** [portfolio-krish.vercel.app](https://portfolio-krish.vercel.app) *(or your deployed URL)*

---

## ⚡ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Library:** [React 18](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)

---

## ✨ Features

- 🖥️ **Cyber / Terminal Aesthetics:** CRT/grid scanline backgrounds, particle networks, and terminal boot loader.
- ⌨️ **Interactive Command Palette:** Quick navigation via `Cmd/Ctrl + K`.
- 🎯 **Interactive Cursor & Scramble Text:** High-tech HUD interaction feel.
- 📱 **Fully Responsive:** Optimized across mobile, tablet, and desktop viewports.
- 🛠️ **Project & Experience Showcases:** Highlighted works including constraint-solver engines, cybersecurity fraud detectors, and hackathon awards.

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js 18+ installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/kkrrishagarwal/krish-portfolio.git
   cd krish-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to view the site.
